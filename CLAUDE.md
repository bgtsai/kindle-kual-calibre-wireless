# CLAUDE.md — notes for AI assistants

KUAL extension (work in progress) that lets desktop calibre's **Connect/share → Start wireless device connection** see a jailbroken Kindle and send/delete books like a USB connection, without KOReader. Client side of calibre's Smart Device App protocol, built on [UNCaGED](https://github.com/shermp/UNCaGED) (GPL-3.0 → this repo is GPL-3.0).

```
├── documents/Calibre 連線.sh     scriptlet book button (Universal Hotfix sh_integration) → toggle.sh
└── extensions/calibre-wireless/
    ├── config.xml               <version> = release tag; bump on every change
    ├── menu.json                generated by render_menu (common.sh); the repo copy is the default
    ├── calibre-wireless.conf    only settings source (filename_chinese)
    └── bin/
        ├── common.sh            paths, log(), notify "<en>" "<zh>" (TrueType font chain, bitmap/eips English fallback), conf_get/conf_set, render_menu
        ├── toggle.sh            connect ↔ disconnect; starts session.sh in background, returns at once
        ├── session.sh           airplane off → wait Wi-Fi (60 s, count-based) → INPUT UDP from calibre's 5 ports → preventScreenSaver 1 → client (FIFO → log + on-screen progress) → reconnect up to 3× on rc 1 → cleanup (sleep allowed, INPUT closed, airplane on, Recent order via ccat, doFullScan, menu)
        ├── filename_toggle.sh   cycles traditional → simplified → original
        ├── pin_toggle.sh        置頂 Calibre 連線 on/off (applies at once when on)
        ├── kual_last_toggle.sh  KUAL 放最後 on/off (applied at the next session end)
        ├── events_record.sh     read-only; 60 s lipc events of BT/VoiceView/UI services → diagnose_connect_events.txt
        ├── diagnose.sh          read-only; diagnose.txt + 120 s powerd/wifid/cmd event recording
        └── calibre-wireless     built by .github/workflows/release.yml (not in git)
```

## Decisions (agreed with the user, don't change without asking)

- KUAL: one top-level item, everything in its submenu (connect/disconnect, `檔名：繁體/簡體/原樣` toggle, diagnose). Settings live only in `calibre-wireless.conf`; the menu just shows/rewrites it.
- Scriptlet book button in `documents/` (needs the Universal Hotfix sh_integration, which the user has — KOReader shows up as a book): connect/disconnect only; its title can't change, so status is shown as on-screen messages.
- Connect: leave airplane mode, wait for Wi-Fi, give up after 60 s. Disconnect (any reason) → back to airplane mode.
- Auto-disconnect: 5 min after connecting with no book; 3 min idle after the last book (`totalBooks`); calibre eject ends immediately.
- Prevent sleep while connected; if it sleeps anyway, reconnect after wake. Cover thumbnails are required.
- Works with bgtsai/kindle-kual-firewall ≥ v1.9 (allows UDP to 255.255.255.255 on calibre's 5 broadcast ports). The INPUT-side UDP reply port is opened by this extension only while connected (like KOReader's `koreader.sh`).
- Folder layout (decided 2026-11-05, v0.5.0): each received book goes in its own folder named after the book title (converted per `filename_chinese`, sanitized like file names): `documents/<title>/<title> - <authors>.<ext>`. Books already on the device are not moved. Deleting a book also removes its Kindle `.sdr` folders (`<name>.sdr`, `<name>_<id>.sdr`, exact-name match) and the book folder if it is then empty.
- Recent order (2026-11-14, v0.10.0): the book button stays first (now + pin_days, default 365), KUAL goes last (2000-01-01); both toggles in the submenu, values in the conf. Change p_lastAccess only through ccat's 9101 API, never sqlite3 writes (icu index). Rejected: 2099 (far future may be hidden), watching cc.db for every change (no inotifyd, UI lags one step, resident process, self-trigger).
- Known risk: right after boot the Kindle may have no default route for minutes (knowledge base 32 §8); broadcast to 255.255.255.255 may fail → fall back to the wlan0 subnet broadcast address.
